# moloko.house

Статичний односторінковий сайт агенції moloko.house.

Хостинг: **GitHub Pages** (перенесено з shared-хостингу adm.tools 13.09.2026, щоб звільнити слот сайту в хостинг-акаунті `rafts`).

- Кастомний домен задано у `CNAME` → `moloko.house`
- `.nojekyll` вимикає обробку Jekyll — файли віддаються як є
- Пошта домену **лишилась на adm.tools** (`MX 0 mx.services`) — DNS-записи MX/SPF/DKIM/DMARC не змінювались

Правки: змінити `index.html`, закомітити в `main` — Pages задеплоїть автоматично.
